## 📖 Tentang Portal

**Portal Kelas 01GSDK001** adalah aplikasi web independen (Single-Page Web Application) yang dirancang khusus untuk memenuhi seluruh kebutuhan administrasi, modul kuliah, rekapitulasi keuangan kas, presensi sekretaris, studio kreator sosmed, hingga ruang diskusi interaktif bagi mahasiswa **PGSD UNPAM Reguler CK**.

> 💡 **Visi Utama:** Menghadirkan transparansi, kemudahan akses perkuliahan 24/7, serta otomatisasi tugas bendahara dan sekretaris kelas berbasis web modern tanpa ketergantungan server backend yang rumit.

## ✨ Fitur-Fitur Utama

<details open>
<summary><b>👑 1. Modul Kas Bendahara Kerajaan (Royal Treasury)</b></summary>

- **Perhitungan Otomatis:** Menghitung Kas Kamis (Rp 5.000/mahasiswa) + Infaq Volunter secara otomatis dan real-time.
- **Matriks Kelunasan:** Grid status interaktif untuk mengubah status kelunasan mahasiswa (*Lunas/Belum*) dalam 1 kali klik.
- **Auto Kamis Reset & Arsip:** Fitur simpan rekapitulasi ke riwayat arsip dan pemutihan status kas setiap minggu Kamis selesai.
- **Cetak Laporan PDF:** Ekspor laporan bukti transaksi kas instan berformat PDF dengan `html2pdf.js`.
</details>

<details>
<summary><b>📋 2. Presensi Sekretaris & Notulensi Perkuliahan</b></summary>

- **Presensi Matriks:** Pencatatan kehadiran (*Hadir, Izin, Sakit, Alfa*) untuk setiap mata kuliah secara cepat.
- **Notulensi Terlampir:** Pembuatan catatan perkuliahan lengkap dengan dukungan tautan lampiran foto, video, dokumen PDF, dan Google Drive.
- **Reset Otomatis:** Fitur pembersihan presensi mingguan setelah sesi perkuliahan selesai.
</details>

<details>
<summary><b>📚 3. Modul Perkuliahan & Tugas Mahasiswa</b></summary>

- **Katalog 10 Matkul:** Daftar lengkap mata kuliah, SKS, dosen pengampu, serta link modul.
- **Penugasan Kelompok & Individu:** Manajemen instruksi tugas dilengkapi deadline, batas waktu, dan lampiran soal/media.
- **Fitur CRUD Lengkap:** Tambah, Edit, Hapus, dan Lampirkan media pada setiap modul/tugas.
</details>

<details>
<summary><b>🎬 4. Studio Kreator & Media Sosial Class</b></summary>

- **Pipeline Konten:** Perencanaan publikasi konten Instagram Reel, TikTok Video, dan Carousel Feed.
- **Penyematan Link Workspaces:** Akses langsung ke Instagram `@01gsdk001.pgsd`, TikTok `@pgsd01gsdk001`, serta workspace Canva & CapCut.
</details>

<details>
<summary><b>🗣️ 5. Forum Q&A & Galeri Dokumentasi</b></summary>

- **Forum Diskusi:** Ruang tanya jawab interaktif antar mahasiswa dengan fitur balasan (*threaded replies*).
- **Galeri Foto/Video:** Dokumentasi kegiatan PKKMB, presentasi, dan perkuliahan dalam format grid responsif.
</details>

## 🛡️ Role & Hak Akses (RBAC)

Portal ini dilengkapi dengan sistem **Role-Based Access Control (RBAC)** untuk menjaga integritas data berdasarkan peran mahasiswa di kelas:

| Peran (Role) | Hak Akses Modul | Deskripsi Akses |
| :--- | :---: | :--- |
| **`developer`** | `*` (Full System) | Akses mutlak ke seluruh modul, admin studio, log sistem, & reset database |
| **`admin`** | `*` (Full Admin) | Akses penuh manajemen konten, pengurus, role user, & visual config |
| **`bendahara`** | `keuangan` | Akses menulis, mencatat, mereset, dan mengarsipkan **Kas Kerajaan** |
| **`sekretaris`** | `sekretaris` | Akses menulis **Presensi Kehadiran** dan **Notulensi Perkuliahan** |
| **`kreator`** | `kreator`, `dokumentasi` | Akses perencanaan **Studio Konten** & **Galeri Foto/Video** |
| **`pj_matkul`** | `materi`, `tugas`, `pengumuman` | Akses mengunggah modul, membuat tugas matkul, & pengumuman |
| **`mahasiswa`** | *Read-Only / Diskusi* | Mode membaca, berdiskusi di forum, & mengedit profil mandiri |

> 🔒 *Untuk peran biasa (Mahasiswa), tombol edit/tambah/hapus pada modul terkunci otomatis dan menampilkan indikator mode baca saja.*

## 💻 Teknologi & Modul Web

Aplikasi dibangun menggunakan stack teknologi web modern berkinerja tinggi tanpa membutuhkan kompiler backend:

```text
├── HTML5 (Semantic Structure & Accessible Accessibility)
├── Tailwind CSS v3 (Utility-First Styling & Custom Glassmorphism UI)
├── JavaScript (Vanilla ES6+ Native Engine & Dynamic DOM Data Binding)
├── Web Audio API (Synthesizer Sound Effects Engine)
├── SpeechSynthesis API (Native Voice AI Text-To-Speech)
├── html2pdf.js (HTML Canvas to PDF Export Engine)
└── FontAwesome v6.5.1 (Vector Icons Palette)
```

## 🚀 Panduan Deploy GitHub Pages

Portal ini 100% siap dijalankan secara publik melalui **GitHub Pages**:

1. **Fork / Clone Repository ini:**
   ```bash
   git clone https://github.com/rickyamrullah/01gsdk001-pgsd.git
   cd 01gsdk001-pgsd
   ```

2. **Push ke Branch Utama (`main` / `master`):**
   ```bash
   git add .
   git commit -m "Deploy Portal Kelas 01GSDK001 v5.0"
   git push origin main
   ```

3. **Aktifkan GitHub Pages:**
   - Masuk ke **Settings** repository GitHub Anda.
   - Buka menu **Pages** di bilah navigasi kiri.
   - Pada opsi **Source**, pilih `Deploy from a branch`.
   - Pilih branch `main` / `master` dan folder `/ (root)`, lalu klik **Save**.
   - Website akan aktif dalam kurun waktu 1-2 menit di URL: `https://<username>.github.io/<repository-name>/`.

## 🔔 Integrasi Webhook Discord

Portal dapat mengirimkan notifikasi audit/log aktivitas perubahan data secara otomatis ke Channel Discord kelas Anda:

1. Buat **Webhook** pada Channel Discord (`Server Settings` -> `Integrations` -> `Webhooks`).
2. Salin URL Webhook Discord tersebut.
3. Jalankan perintah JavaScript berikut melalui Developer Console browser Anda setelah login sebagai Admin/Developer:
   ```javascript
   window.setDiscordWebhookSecurely('https://discord.com/api/webhooks/YOUR_WEBHOOK_URL');
   ```
4. Setiap perubahan data (Kas, Tugas, Pengumuman, Profil) akan mengirimkan **Embed Card Alert** otomatis ke Discord!
