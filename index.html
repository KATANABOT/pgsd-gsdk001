Buku Panduan & Tutorial Penggunaan Website

Panduan langkah demi langkah cara menggunakan semua fitur website untuk seluruh peran

1. Panduan Login & Pemulihan Akun

  • Login Pertama: Masukkan nama Anda di form login. Password default adalah 1234.
  • Ganti Password Mandiri: Klik tombol ikon kunci di header kanan atas untuk mengubah kata sandi Anda.
  • Lupa Password: Klik "Lupa Kata Sandi?" di login gate untuk mereset kata sandi tanpa kembali ke layar login awal.
  • Profil & Bio Data: Klik nama Anda di header untuk mengunggah Foto Profil, Video Avatar, & mengubah Bio Data Mahasiswa.

2. Kas Bendahara Kerajaan & Presensi Sekretaris

  • Matriks Kas Kamis Mewah: Semua entri kas kini dilengkapi tombol Edit, Tambah, Hapus & Lampiran Media. Ditata dengan nuansa Kerajaan Presiden Mewah.
  • Reset Kamis Otomatis: Setiap hari Kamis selesai, data kas & presensi sekretaris akan di-reset otomatis dan diarsipkan aman di riwayat.
  • Presensi Sekretaris: Status kehadiran mahasiswa dapat di-edit, diubah, & dihapus dengan data terpusat di bawah agar tidak hilang.

3. Lampiran Foto, Video, Dokumen & Link

  • Semua menu (Materi, Tugas, Pengumuman, Notulensi, Forum, Dokumentasi, Referensi, Kreator, Kas) mendukung fitur Edit, Tambah, Hapus & Pengiriman via Dokumen, Foto, Video, & Link.
  • Setiap entri yang memiliki lampiran media langsung menampilkan tombol pratinjau media.

4. Visual Config & Admin Studio

  • No-Code Editor: Admin dapat mengubah judul website, pengurus, logo custom, hingga banner tanpa menyentuh kode.
  • Ganti Background & Tema: Gunakan tombol di header untuk beralih antara tema warna dan variasi background dinamis.
